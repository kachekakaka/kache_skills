# 测试安全

## 测试现场

- 默认测试根为项目同级的 `kache_skills_test/`，每次运行使用其下独立的 `<run-id>/`。
- 本文档骨架及文档门禁不创建、复用、检查或清理测试根和测试 run。
- 默认测试根已经存在但没有当前项目合法所有权标记时，必须停止并取得复用或改名决定。
- 输出解析后仍须位于本次直接 run；符号链接、junction、reparse point 或路径逃逸必须失败关闭。

## 数据与进程

- 本项目测试不涉及真实用户数据，真实数据保护流程不适用。
- 本项目测试不启动、停止或控制产品进程，产品进程所有权与清理流程不适用。
- 测试直接需要公开只读联网时，只有无需认证、不上传本地或非公开内容、不收费且不改变外部状态才默认允许；认证
  或私有访问、上传、外部写入、费用及明显大规模或长时间下载按 [测试协议](PROTOCOL.md) 另行授权。
- Cookie、Token、Key、密码、真实用户数据和原始运行现场不得写入仓库或交接摘要。

## 输出与清理

- 由本任务创建且所有权明确的成功临时输出应在取证后精确清理；失败、阻断或不可判定输出只有确有复查价值时才保留，
  并同时记录所有者和复查日期。需要长期保存的历史证据必须明确选择，不设置后台或宽泛目录 GC。
- 方案或当前任务已经明确列出清理本次创建的精确 run 目录时，实施授权覆盖该清理；执行前仍须重新验证所有权
  并展示精确绝对路径。
- 未列明清理、超出本次精确 run、使用宽泛匹配或未解析路径、其他 run、测试根、项目目录、仓库外非任务产物或
  所有权不明的内容必须取得精确删除授权。
