# 项目文档 Skill 可选行为样例

本目录保存少量用户可观察行为样例。它们不是普通机械门禁，没有固定矩阵、固定样本数量、性能门槛、方案接力或长期运行
记录；只有用户明确要求前向试用并授权隔离现场后，才选择与当前变更直接相关的场景。

## 使用方式

1. 从 [行为样例](contract-cases.md) 选择一个或多个真实相关场景，在仓库外创建未受旧运行产物污染的临时项目。
2. 新任务只接收对应 Skill、临时项目和自然用户请求；不要提供预期答案、旧诊断或其他场景结果。
3. 观察 Skill 是否保持显式、只读、只报告和一层证据边界，以及建议是否通过反过度治理门。
4. 记录实际范围、是否发生写入、主要发现、越界行为和未覆盖内容；成功现场取证后精确清理。

场景可以单独运行，未选择的场景保持 `not_run`。静态包装检查通过不能替代真实行为结果；没有执行行为样例时，也不能
声称模型行为已经通过前向验证。

## 判定

- `passed`：所选场景进入可判定阶段，Skill 没有写入或扩张范围，并满足该场景的可观察预期。
- `failed`：出现漏报关键问题、误报标准缺失、目标项目写入、方案生成、无界取证或无消费者资产建议。
- `blocked`：缺少隔离项目、任务能力或必要授权，未进入可判定阶段。
- `inconclusive`：任务中断或现场污染使结果无法解释。
- `not_run`：场景没有执行。
