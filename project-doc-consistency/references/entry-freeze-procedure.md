# 入口冻结操作规程

本规程只用于既有项目的入口和治理锚点冻结，不审计产品事实。

## 1. 精确读取适用规则

从已知目标根开始，机械拼接 `<当前目录>/AGENTS.md`，再逐级拼接每个祖先目录的精确路径直到卷根。逐个使用
精确文件读取；路径不存在就记录不存在。禁止 glob、目录列举、递归搜索、工作区搜索或磁盘搜索。任何一次宽
搜索都使本次入口冻结不合格，应立即停止并报告执行偏差。

## 2. 建立入口文件结构图

对根 README、当前文档索引、测试索引和允许的治理稳定入口，分别在该精确文件内执行以下只读扫描：

1. 用 `output_mode=content`、`line_numbers=true`、`only_matching=true`、零上下文的精确文件匹配，同时返回完整
   ATX 标题候选行和 fenced code 边界行：
   `^ {0,3}#{1,6}[ \t]+.*$|^ {0,3}(?:\x60{3,}|~{3,}).*$`
2. 按同类围栏标记配对，丢弃围栏内部所有 `#` 候选；没有闭合的围栏之后不再接受标题候选。
3. 另做一次 `only_matching=true` 的无上下文匹配，只返回 Markdown 链接 token：
   `\[[^]]+\]\((<[^>]+>|[^)]+)\)`；同样丢弃
   围栏内部结果。只从 token 提取链接目标，不读取链接所在普通正文整行。
4. 禁止在全文件匹配任意含 `/`、反斜杠、反引号、扩展名、URL 或 API 路径的正文/裸路径行。

围栏外 token 若位于清理后“当前文档/测试导航、职责、所有权或生命周期”标题下，且所在行是独立 Markdown
表格行或列表项，可以再对该精确行做一次 `limit=1` 读取，用同一行紧邻的职责/角色文本归属路径。不得读取
前后行；普通段落、多条互不相关声明或无法分离职责的行只保留 token，属性记 `未归属`。

身份前言只定向读取 1–4 行。导航不读取章节正文；只使用围栏外 Markdown 链接 token、清理后标题上下文和上述
允许的单行结构记录。导航 prose 和行内代码中的裸路径不作为 A 阶段直接链接；如果项目只用这些形态接线，相关
锚点记 `证据不足`。

规范命令只允许来自当前测试索引或治理稳定入口中已由清理后标题定位的 fenced code block。只读取围栏起止行
之间的代码，单块最多 40 行，不读取围栏前后的说明；治理稳定入口只有一个一级标题和唯一 fenced block 时，
该块可作为规范命令块。代码块中的精确仓库相对路径可以冻结，代码块外的裸路径不可以。块数或语义不唯一、
超过预算或工具不能限定行范围时，记相应锚点 `证据不足`，不得改读整个章节。

## 3. A 与 B/C 的隔离

A 只冻结 Markdown 链接目标、允许的规范命令块中的精确路径，并为每条路径写定：来源文件与行/命令块、原文
链接标签或最近的清理后标题、唯一所属治理属性。原文没有明确职责时记 `未归属`；不得根据文件名或路径含义
猜属性。同一路径只有被入口以两个明确职责分别接线时，才能建立两条不同属性记录。当前真源、backlog、归档/
历史索引、Protocol、SAFETY、suite、CI、helper、实现和 `full` 目标正文都不得在 A 打开。

B 检查第 1 项需要当前真源职责时，只在该精确文件内查找第一个二级标题：匹配 `^##[ \t]+`，无上下文且
`head_limit=1`；另匹配第一个 fenced code 边界。若围栏先于二级标题，直接记证据不足。否则只读取 1 到
`min(20, 首个二级标题行号 - 1)`；没有二级标题时最多读取前 20 行。不得扫描全部标题或跟随前言链接。

进入 B 的每一项前，先只看该行冻结清单：任一必需证据角色为 `缺失` 或 `未归属` 时，立即写 `证据不足`，
该属性的一份证据正文也不得打开。角色齐全时也只能打开唯一归属于当前属性的路径；其他属性和未归属路径绝不
能复用、试读或按文件名推断。`full` 活动文件在 C 才完整读取；`incremental` 内容种子也只在 C 读取。任何提前
读取、宽搜索、跨属性复用或围栏内伪标题污染都必须报告为机制执行偏差，不能用最终账本正确来抵消。
