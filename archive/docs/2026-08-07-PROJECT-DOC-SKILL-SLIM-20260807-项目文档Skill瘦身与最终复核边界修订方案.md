1. 普通实施任务只执行“最终范围与漂移复核”：重新冻结最终入口与所有者，核对方案确定切片，并检查本次修改路径

   Registry 全局审计。出现边界外新问题时保持方案活动并记录残余或申请授权差额。
2. 成熟等价项目不因存在测试入口或测试根而无条件加载任一标准路线参考；`skeleton-rules.md` 只在采用标准骨架的
   项目检查（含新建）、明确迁移或用户要求标准结构比较时加载，`testing-baseline.md` 只在标准测试治理或标准
   T-DOC／验证规划适用时加载。
3. 同一 Skill 包中的测试资产调查、项目级 Skill 根排除、阶段停点和授权交接各保留一个运行时权威表述，其余位置
   使用短引用或删除重复段落。
4. 删除“由 skeleton 判断测试成本”的歧义；自定义 Skill 根只接受用户、适用项目规则或本轮已经进入范围的精确
   配置声明，不为发现自定义根扫描全部工具配置。

不新增 Skill、参考文件、ADR、manifest、配置解析器、脚本或新的治理层级；不修改 T-DOC 实现和既有七类标准根。
