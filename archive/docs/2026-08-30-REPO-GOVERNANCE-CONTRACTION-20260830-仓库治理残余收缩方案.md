## 1. 目标与不变量

本次治理只收缩本仓库已经失去消费者、已经退出产品范围或过度绑定实现形状的内容，不改变三个建议型审计 Skill 的行为。
实施结果必须同时满足：

1. 保留本仓库的 `待确认 → 待实施 → 实施中 → 归档` 方案生命周期，以及语义确认不等于实施授权的边界。
2. 活动文档不再把写入迁移、批量改造、正式认证或跨平台支持列为当前产品义务。
3. 被替代的 ADR 原文进入历史归档；活动入口只展示仍然有效的决定。
4. 个人 Skill 仍从干净、已提交的源仓库精确安装，保留来源提交、逐文件哈希和显式漂移校验。
5. 只承诺当前 Windows 环境；不测试、不承诺其他平台，也不增加主动平台阻断。

不新增 CI、测试套件、证据 schema、ADR 或术语。三个 `SKILL.md`、三个 `agents/openai.yaml`、`AGENTS.md` 和现有方案生命周期
语义不在修改范围内；允许在原文档补充已经确认的消费者和支持边界。

## 2. 已确认决定

| 主题 | 决定 | 理由 |
| --- | --- | --- |
| 方案生命周期 | 本仓库继续强制使用现有状态与授权停点 | 真实失败是模型把讨论结论误作实施授权；当前规则有明确消费者 |
| 历史 ADR | 保留原意并移入归档，活动索引只列当前决定 | 降低当前事实噪声，同时保留设计历史 |
| 安装来源 | 保留精确镜像、`SOURCE-PROVENANCE.json`、逐文件哈希、`--verify-only` 和干净提交要求 | 防止个人副本漂移，并确保提交号能够还原安装内容 |
| 平台支持 | 只承诺当前 Windows 环境，不阻止其他系统尝试运行 | 不建立没有持续消费者的跨平台验证和 CI 设施 |
| 测试边界 | 验证可观察包装和安装行为，不禁止未来有合理消费者的整个目录类别 | 避免把当前文件形状冻结成永久产品合同 |

方案生命周期和授权停点是既有项目决定，本次只补明其消费者；其余决定是可逆的维护与支持范围收缩。没有新的决定同时满足
“难以逆转、缺少背景会令人意外、来自新的真实取舍”三个条件，因此不新增 ADR。没有出现新的领域术语，因此不修改
`CONTEXT.md`。
