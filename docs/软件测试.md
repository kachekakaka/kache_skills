# 软件测试

本文件只列本仓库当前稳定验证入口，不规定目标项目必须复制的 Registry、目录或执行类别。

- [项目文档 Skill 轻量验证](../SoftwareTesting/doc_consistency/README.md)
  - `test_markdown_links.py`：检查非历史 Markdown 的本地链接和标题锚点。
  - `test_project_doc_skill_responsibilities.py`：检查三个 Skill 的显式调用和包内运行依赖边界，不固定支持文件目录。
  - `test_project_doc_skill_installer.py`：检查三个名称分别单包镜像和来源清单，不锁定内部映射。
- [项目文档 Skill 可选行为样例](../SoftwareTesting/manual/project_doc_skills/README.md)：只在用户显式要求时选择具体隔离场景；
  不作为普通验证的固定成员。

测试说明不保存日期、耗时、固定数量、运行编号、哈希或动态结果。实际选择和结果只在当前实施记录中说明。
