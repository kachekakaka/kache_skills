# 建议型审计判断证据问题而不是治理合规

固定骨架、持续决策访谈和不可变收缩基线都会把文档检查变成项目治理认证。现决定 Skeleton 只报告入口失效、所有者冲突及活动／历史边界不清等真实结构问题，不因缺少标准文件或路径不同判定失败；Consistency 对当前权威无法裁决的冲突只报告证据、影响和选项，交给后续任务决定；Contraction 直接使用当前活动文档和一层直接证据，事实、所有者或消费者不清时把对应内容列为收缩保留项，不要求不可变 SHA、工作区干净或事先完成一致性整改与验证，也不阻断其他独立内容的检查。该决定替代 ADR-0002 的六项治理合格门和 ADR-0012 的不可变收缩基线要求，保留三个 Skill 的职责分离和只读边界。
