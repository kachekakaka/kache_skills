# 按副作用而不是工具名称划分授权

标准骨架原先把命令、Git、联网、删除和生命周期关闭作为粗粒度授权类别，容易让本地读取、公开资料查询、普通
验证、精确文件删除及方案收尾产生重复确认。工具或协议名称本身不能准确表示风险：Git 查询可以完全只读，而
`reset --hard`、`clean`、历史改写和强推即使没有创建普通 commit，也可能丢失工作或改变共享状态；公开文档
查询与上传源码、写入外部系统或调用付费接口也不应属于同一授权等级。

现决定按实际副作用分级。本地文件读取、搜索和不改变工作区、索引、引用或远端状态的 Git 查询默认允许。用户
明确授权“按已确认方案实施”时，该授权覆盖确定范围内的文件新增、修改、重命名和删除、列明的普通验证、结果
记录，以及完成条件满足后的待办状态更新、方案归档、索引更新和精确任务清理。

访问公开信息的只读联网也默认允许，但必须同时满足：无需登录或认证；只读取公开资源；不向服务提交本地文件、
源码、提示上下文、凭据、真实数据或其他非公开内容；不产生费用；不发布、提交、留言或改变外部业务与账户状态。
公开文档、搜索结果、公开仓库和包元数据可以据此读取，不因使用浏览器、命令行或 API 而改变分类。

已确认方案列明的普通下载和公开资源获取随实施授权覆盖；来源、用途、写入目标、规模和副作用不变时不重复申请。
需要认证或访问私有资源、上传本地或非公开内容、改变外部状态、产生费用、明显大规模或长时间下载，以及产品进程、
真实数据、全量测试和正式认证仍须明确授权。范围或副作用变化时只申请授权差额。

commit（含 amend）、push、PR、发布和安装，以及覆盖工作区、丢失修改、改写历史或改变远端状态的 Git 操作仍须
明确授权。方案未列明、超出确定范围、使用宽泛匹配或未解析路径、仓库外非任务产物、所有权不明或涉及真实数据
的删除须取得精确授权；方案列明的仓库内精确删除和本任务创建且所有权可验证的精确临时产物清理不再重复申请。

方案保存继续不构成实施授权，Skill 也不恢复施工阶段。普通任务在完成条件和方案列明的验收要求满足且没有授权
差额时，可以在同一次实施授权下关闭方案；需要新的语义决定、用户明确验收或高风险清理时仍须停下。方案关闭与
commit、push、PR 相互独立，任何一方都不成为另一方的前置条件或隐式授权。

本决定细化 ADR-0004 至 ADR-0006 的授权交接和生命周期语义，不改变检查与保存分离、两个 Skill 保存方案后退出、
活动方案完成后退出活动入口或等价既有治理保留自身更严格规则的决定。
