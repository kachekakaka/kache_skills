# 保留 Skill 名称并只验证可观察边界

重命名三个已安装 Skill 会带来调用和引用迁移，而保留现有完整 T-DOC 与精确文案断言又会延续过度治理。现决定保留 `project-doc-skeleton`、`project-doc-consistency` 和 `project-doc-contraction` 三个名称，通过描述明确其建议型审计职责；本源仓库的文档门禁收缩为只捕获失效 Markdown 链接等真实直接故障的自用轻量门禁，不再检查标准骨架、Registry、方案生命周期或源／资产逐字节同步；Skill 回归改为少量隔离行为场景，验证显式调用、只读、只报告、不携带 T-DOC 和一层证据边界，不再以精确提示词 Token、固定段落或旧长流程步骤作为合同。
