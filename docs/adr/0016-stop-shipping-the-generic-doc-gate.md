# Skeleton 不再交付通用文档门禁

标准 Skeleton 携带约 1,900 行通用 T-DOC 实现和规则夹具，会让小项目仅为文档结构承担额外测试资产、同步关系和维护成本。现决定从 `project-doc-skeleton` 的交付合同中移除通用 T-DOC：Skeleton 可以根据当前项目证据指出链接、入口或生命周期问题并建议合适的检查方式，但不携带、不安装、不要求自动门禁，也不以缺少门禁判定项目治理不合格；项目确有自动检查需求时，由普通任务按真实消费者和失败模式另行实现。该决定替代 ADR-0013 中把 T-DOC 作为标准骨架固定能力的部分，但不自动决定本源仓库自用检查器的去留。
